# Proposal: Supervisor sidebar-aligned action colors

## Why

Supervisor primary actions and selected tabs currently use a mixture of solid red and red-orange gradients. The Supervisor sidebar uses the solid brand-700 color, so those controls should share its visual anchor.

## What changes

- Use the Supervisor sidebar brand color for primary buttons and primary links across Supervisor pages.
- Use the same color for selected Supervisor tabs and the darker brand color on hover.
- Preserve neutral inactive tabs and secondary buttons, danger actions, disabled states, focus indicators, dimensions, labels, and behavior.
- Keep Admin, Cashier, and public surfaces unchanged.

## Scope

Presentation-only. No API, data, permissions, workflow, or financial behavior changes.
