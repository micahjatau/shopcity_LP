# Pilot Training — Supervisor

## Goals

- Triage pilot incidents quickly using authoritative read paths.
- Escalate operational or financial anomalies with evidence.
- Keep branch operations aligned with the approved release candidate.

## Required skills

1. Read pilot operations summary and identify unhealthy signals.
2. Review duplicate-credit, lost-card, SMS-failure, and outbox-backlog runbooks.
3. Verify request IDs, receipt numbers, card serial numbers, and operator context before escalation.
4. Pause risky activity when reconciliation or release integrity is in doubt.

## Completion evidence

- Supervisor can explain when to halt transactions versus when to monitor.
- Supervisor can produce a sample incident note with request IDs and affected identifiers.
- Supervisor signs off that direct ledger mutation is prohibited.
