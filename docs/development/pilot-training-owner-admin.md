# Pilot Training — Owner/Admin

## Goals

- Approve pilot launch only with complete evidence.
- Review operational health using admin-only signals.
- Coordinate rollback, security, and support escalation decisions.

## Required skills

1. Validate release SHA/image digest against the approved evidence bundle.
2. Review deployment, rollback, restore, security, and performance evidence.
3. Read the pilot operations summary and understand escalation thresholds.
4. Coordinate incident response without requesting ad hoc database edits.

## Completion evidence

- Owner/admin reviews the approved Sprint 5 evidence bundle.
- Owner/admin can identify the rollback trigger and responsible approver.
- Owner/admin acknowledges provider-managed backup responsibility and restore drill limits.
